# 中国企业招聘信息平台

> Fortune China 500 企业 · CS专场 · 零依赖单文件运行

一个帮助计算机大类学生快速找到招聘信息的工具。覆盖 **111 家** Fortune 中国 500 强中招聘 CS 相关岗位的企业，包含国内互联网巨头和知名外企中国研发中心，提供公司官网和校招投递入口。

---

## 快速开始

### 方式一：HTA 程序（推荐，发给朋友用这个）

> ⚠️ 首次双击可能弹出 Windows SmartScreen 提示，点击「更多信息」→「仍要运行」即可。这是因为 HTA 文件没有数字签名。

1. 双击 `企业招聘信息平台.hta`
2. 程序以独立窗口运行，搜索公司、筛选行业、收藏心仪企业
3. 点击卡片上的 **「投递简历」** 跳转到企业官方招聘页面

### 方式二：浏览器打开

> 适用于 macOS / Linux，或者想用浏览器查看的用户。

1. 双击 `index.html`（或用浏览器打开）
2. 功能和 HTA 版本完全一致

### 方式三：发给微信好友

将 `企业招聘信息平台.hta` 直接拖入微信聊天框发送。对方接收后双击即可运行。

## 项目结构

```
├── 企业招聘信息平台.hta   ← 分发用单文件（Windows 双击即用）
├── index.html             ← 浏览器版入口
├── README.md              ← 本文件
├── css/
│   └── style.css          ← 样式表（CSS Grid 响应式布局）
├── js/
│   ├── data.js            ← 111家企业数据集
│   ├── app.js             ← 核心逻辑（搜索/筛选/渲染/收藏）
│   └── utils.js           ← 工具函数（localStorage/防抖/格式化）
└── assets/
    └── icon.svg           ← Logo 图标
```

### 各文件职责

| 文件 | 干什么的 | 关键设计决策 |
|------|----------|-------------|
| `企业招聘信息平台.hta` | 单文件可执行程序，内联了所有 CSS/JS/SVG | 零依赖分发，微信发一个文件对方双击即用 |
| `index.html` | 浏览器版入口，引用外部 CSS/JS | 方便开发调试，也支持非 Windows 用户 |
| `css/style.css` | 全部样式：CSS变量体系、网格布局、卡片组件、响应式断点 | 通过 `:root` 变量管理3色调色板，改一处全局生效 |
| `js/data.js` | 111家企业完整数据集，每家14个字段 | 嵌入为JS变量而非JSON，绕过 `file://` CORS限制 |
| `js/app.js` | 核心交互逻辑：搜索→筛选→排序→渲染 数据管线 | IIFE隔离作用域，`filterAndRender()` 是唯一数据入口 |
| `js/utils.js` | 三个工具函数：收藏夹CRUD、防抖、城市格式化 | 纯函数，不依赖DOM，便于测试和复用 |
| `assets/icon.svg` | 页面 Logo 图标 | SVG内联，零额外请求 |

## 技术选型

- **纯 HTML + CSS + Vanilla JavaScript**，零框架、零依赖
- **CSS Grid** 实现响应式卡片布局
- **localStorage** 持久化收藏夹数据
- **HTA (HTML Application)** 打包为 Windows 原生程序

### 为什么不用 Electron / React / Vue？

本项目定位是"发给同学直接用的工具"：
- **Electron** 打包后 150MB+，微信发不了，更新困难
- **React/Vue** 需要构建工具链，修改数据需要重新 build
- **纯 HTML/JS** 只有 101KB，用记事本就能改数据，双击即用

## 自定义与更新

### 添加新公司

编辑 `js/data.js`，在对应分类区块中添加新条目：

```javascript
{
  id: "newcompany",           // 唯一ID（英文+数字+连字符）
  nameCN: "新公司名称",
  nameEN: "Company Name",
  industry: "互联网",
  categories: ["互联网"],
  website: "https://www.example.com",
  careerPage: "https://career.example.com",
  careerCampus: "https://campus.example.com",
  positions: ["后端开发", "前端开发", "算法工程师"],
  description: "公司简介一句",
  fortuneRank: 100,
  tags: ["标签1", "标签2"],
  hiring: true,
  hasCampusRecruit: true,
  cities: ["北京", "上海"]
}
```

### 同步到 HTA 文件

修改 `js/data.js` 后，将新增的条目同步复制到 `企业招聘信息平台.hta` 中对应的数据区域即可。
