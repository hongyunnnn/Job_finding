```
│  浅绿 BG        #e8f8f0  ████████████████████████████    │
│  绿底 BG        #f4fdf8  ████████████████████████████    │
│                                                         │
│  白色 White     #ffffff  ████████████████████████████    │

│  深海军蓝 Navy  #2c3e50  ████████████████████████████    │
│  海军蓝浅       #5a6d80  ████████████████████████████    │
│  海军蓝边框     #dde4ea  ████████████████████████████    │

```

浅变体（#e8f8f0、#27ae60、#dde4ea 等）属于同色系衍生，不计为新颜色。

## 应用规则

| 元素 | 颜色 | 说明 |
|------|------|------|
| 页面背景 | `#f5f7fa`（海军蓝底） | 柔和，不刺眼 |
| 卡片背景 | `#ffffff`（白色） | 纯白，与背景形成层次 |
| 主按钮 | `#2ecc71`（绿色） | 醒目操作（投递简历） |
| 次按钮 | 白色底 + 绿色边框 | 次要操作（官网） |
| 标题文字 | `#2c3e50`（海军蓝） | 高对比，易读 |
| 辅助文字 | `#5a6d80`（海军蓝浅） | 降低视觉权重 |
| 激活状态 | `#2ecc71` 填充 | 分类按钮、收藏星标 |
| 悬停效果 | `#27ae60`（深绿） | 比主色深一级 |
| 边框/分割 | `#dde4ea`（海军蓝边框） | 轻量分割 |

## 排版

| 元素 | 字号 | 字重 | 说明 |
|------|------|------|------|
| 页面标题 | 1.25rem (20px) | 700 | Header 中的大标题 |
| 卡片标题 | 1.05rem (17px) | 700 | 公司中文名 |
| 卡片副标题 | 0.75rem (12px) | 400 | 公司英文名 |
| 正文 | 1rem (16px) | 400 | 搜索框等 |
| 辅助信息 | 0.78rem-0.85rem | 400 | 城市、标签、按钮 |

## 字体栈

```css
font-family: system-ui, -apple-system, "Segoe UI",
             "PingFang SC", "Microsoft YaHei", sans-serif;
```

不引入外部 Web 字体，零网络请求。

## 间距系统

| 层级 | 值 | 用途 |
|------|------|------|
| xs | 4-6px | 标签间距 |
| sm | 8-10px | 按钮内部、图标间距 |
| md | 12-16px | 卡片内边距、区块间距 |
| lg | 18-20px | 卡片间隙、区块内边距 |
| xl | 24-28px | 页面边距 |

## 圆角

| 元素 | 值 |
|------|------|
| 卡片 | 12px |
| 搜索框 | 28px |
| 按钮 | 20-24px |
| 标签 | 8-12px |
| 头像 | 8px |

## 阴影

| 层级 | 值 | 用途 |
|------|------|------|
| sm | `0 1px 3px rgba(44,62,80,0.06)` | Header、卡片 |
| md | `0 4px 16px rgba(44,62,80,0.08)` | 卡片悬停 |
| lg | `0 8px 30px rgba(44,62,80,0.12)` | 浮动按钮 |

## 响应式断点

| 断点 | 列数 | 说明 |
|------|------|------|
| >= 1200px | 4 列 | 大屏/外接显示器 |
| 900-1199px | 3 列 | 笔记本屏幕 |
| 600-899px | 2 列 | 平板 |
| < 600px | 1 列 | 手机 |

## SVG 图标规范

- 全部内联，零外部请求
- `viewBox="0 0 24 24"` 统一画布
- `stroke="currentColor"` 继承文字颜色
- 14px-20px 显示尺寸

## 动画

| 元素 | 动画 | 时长 |
|------|------|------|
| 卡片悬停 | `translateY(-2px)` + 阴影增强 | 0.2s ease |
| 按钮/链接 | 颜色过渡 | 0.2s ease |
| 回到顶部 | opacity 淡入淡出 | 0.2s ease |
| 搜索框聚焦 | 边框变绿 | 0.2s ease |
| 星标悬停 | `scale(1.2)` | 0.2s ease |
