# 开发需求文档

## 项目背景

计算机大类学生在找工作时面临"不知道哪些公司在招人、去哪里投简历"的问题。需要一个工具来聚合 Fortune 中国 500 强中招聘 CS 相关岗位的企业信息。

## 核心需求

| # | 需求 | 优先级 | 状态 |
|---|------|--------|------|
| 1 | 覆盖至少100家招聘CS岗位的企业 | P0 | ✅ 已完成（111家） |
| 2 | 展示企业名称、官网链接、招聘页面链接 | P0 | ✅ 已完成 |
| 3 | 重点覆盖互联网/科技相关职业 | P0 | ✅ 已完成 |
| 4 | Windows 设备运行，零依赖 | P0 | ✅ 已完成（HTA + HTML） |
| 5 | 简洁美观，绿白色主调，不超过3种颜色 | P0 | ✅ 已完成 |
| 6 | 搜索功能（公司名、职位、关键词） | P0 | ✅ 已完成 |
| 7 | 行业分类筛选 | P1 | ✅ 已完成（16个分类） |
| 8 | 收藏夹功能（本地持久化） | P1 | ✅ 已完成 |
| 9 | 校招专区筛选 | P1 | ✅ 已完成 |
| 10 | 微信分发 | P1 | ✅ 已完成（101KB单文件） |
| 11 | 响应式布局（手机/平板可用） | P2 | ✅ 已完成 |

## 用户画像

- **主要用户**：计算机大类本科/硕士应届生
- **使用场景**：秋招/春招期间，每天浏览查看有哪些公司在招人
- **分发方式**：微信发送 .hta 文件给同学
- **设备**：Windows 笔记本/台式机
